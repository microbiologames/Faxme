# Faxme

Du courrier papier entre enfants, sans écran.

Deux boîtes dans deux maisons. Un enfant glisse une lettre écrite à la main dans la
fente, appuie sur un bouton : elle est numérisée et envoyée. Chez l'autre enfant, une
cloche sonne et une lumière s'allume ; il appuie, la lettre sort imprimée sur papier.

Pas d'écran, pas de compte, pas de clavier, pas d'autre usage possible. Les
destinataires sont un carnet fermé configuré par les parents.

État : **concept**. Rien n'est encore implémenté.
